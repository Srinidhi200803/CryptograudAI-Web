
🛡️ CryptoGuard AI
Understand Your Crypto Risk

CryptoGuard AI is an educational crypto portfolio risk analysis web application designed to help users explore portfolio-related information through an interactive interface.


🎯 Problem Statement
Understanding crypto portfolio risk can be challenging for beginners. Portfolio allocations and risk-related information may be difficult to interpret.
Our project aims to make these concepts easier to explore through a simple web experience.

✨ Features
- Portfolio Analyzer
- Visual portfolio and risk information
- AI Assistant for risk-related explanations
- What-If Simulator, where available
- Beginner-friendly interface
